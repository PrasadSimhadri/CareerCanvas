# BuildUrSite - Professional Portfolio Builder

BuildUrSite is a powerful, user-friendly platform that allows anyone to create a professional portfolio website in minutes. 

## Features
- **5 Stunning Templates**: Choose from Minimal, Creative, Sidebar, Futuristic, or Sleek layouts.
- **Easy Form Builder**: Simple, structured data entry for your professional details.
- **Shareable Links**: Get a unique URL (e.g., `buildursite.vercel.app/yourname`) to share with recruiters.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile viewing.

## Getting Started
First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack
- **Frontend**: Next.js 14, Tailwind CSS, Framer Motion
- **Backend**: MongoDB, Mongoose
- **Authentication**: JWT, Google OAuth
- **Storage**: Cloudinary
